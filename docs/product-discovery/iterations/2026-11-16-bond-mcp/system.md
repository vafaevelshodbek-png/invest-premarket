## AI-подходы

Выбрать: LLM, AI-агент.

Объяснение:

LLM уточняет условия инвестора и объясняет данные об облигациях, эмитентах и портфеле. Один AI-агент выбирает необходимые запросы из разрешённых инструментов T-Invest MCP. Фильтры и финансовые расчёты выполняет код. Ответ опирается на полученные сведения с указанием источника и даты. Выигрыш AI проверим относительно поиска и шаблонных пояснений.

## Технический контур MVP

Веб-интерфейс объединяет диалог, подборку выпусков и карточку проверки покупки. Backend хранит состояние запроса, подтверждённые ограничения и выбранные варианты. MCP-клиент подключается к серверу Т-Инвестиций с токеном только для чтения. Брокерские данные поступают через T-Invest MCP, источником аналитических выводов служат его ответы и расчёты приложения.

При подключении backend получает tools/list и проверяет нужные инструменты безопасными запросами. Из реально доступных возможностей формируется ограниченный набор функций для агента: поиск и параметры облигаций, котировки, выплаты, портфель, рейтинги, финансовые сведения и новости. Отдельные методы Invest API не подменяют отсутствующие MCP-инструменты. Для аналитики эмитента заранее проверяется связь юридического лица с источником показателей.

Основная модель-кандидат: YandexGPT Pro с вызовом функций. Доступную версию выберем по проверке понимания русских запросов, корректности вызовов и объяснений. Модель предлагает действия, backend проверяет аргументы и выполняет запросы. Перед анализом код сокращает каталог по жёстким условиям, чтобы агент обогащал данными только кандидатов. Ограничиваются число вызовов, объём контекста и время сессии.

Расчётный модуль отдельно проверяет условия и считает деньги, денежные потоки и портфельные изменения. Валидатор сверяет числовые утверждения и ссылки на полученные данные. В SQLite хранятся справочник, параметры запросов и сведения о происхождении данных. Датированные ответы MCP сохраняются для воспроизводимой проверки с разграничением доступа. Токен и идентификатор счёта остаются на backend, модель получает необходимые обезличенные сведения.

MVP охватывает ограниченный каталог рублёвых выпусков с фиксированным купоном нескольких эмитентов с проверенным покрытием. В нём сохраняются все три функции: самостоятельный подбор по запросу, разбор эмитента и проверка покупки в портфеле. Работающий MVP и авторизованное подключение пока не заявлены. Полные отчёты, внешние новостные архивы и платные базы для этого контура не требуются.
