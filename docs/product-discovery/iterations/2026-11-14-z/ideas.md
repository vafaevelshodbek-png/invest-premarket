## Рамка хакатона

Т-Банк ищет новые сценарии работы с инвестициями на инфраструктуре Т-Банка и MCP, «которых пока нет на рынке». Номинации: AI-агент для инвестиций, новый инвестиционный опыт, AI-торговый робот и Гран-при. Жюри оценивает новизну, ценность для инвестиционного бизнеса, качество реализации и потенциал развития. К 3 декабря нужен работающий сквозной сценарий, на очном этапе 21 ноября сравниваются минимум три концепции ([анонс](https://kod.ru/t-invest-premarket-ai-chellendzh), [условия](https://github.com/vafaevelshodbek-png/invest-premarket/wiki/Hackathon)).

Что уже есть и новизной не считается: подключение внешних агентов по MCP, ассистент по портфелю, сводки, алерты и ребалансировка из [статьи Т-Банка про MCP](https://habr.com/ru/companies/tbank/articles/1086714/), календарь оферт с напоминаниями в приложении, робо-эдвайзер, AI-саммари новостей у ВТБ, создание робота по описанию у Финама. Подробности: [исследование соответствия хакатону](https://github.com/vafaevelshodbek-png/invest-premarket/pull/51).

## Как оценивали

По 1-3 балла: **Н** попадание в номинацию, **Т** использование инфраструктуры Т-Банка и MCP, **Нв** новизна, **MVP** рабочий сценарий вчетвером за 10 дней, **AI** нужен по делу, **П** можно честно проверить экспериментом. Максимум 18. Оценки являются предложением для обсуждения.

## Предложение

**Основная: 1, «Второе мнение перед сделкой».** Первая версия ограничена облигациями и признаками разгона бумаги. Идеи 2 и 3 входят в неё как модули: проверка поста, с которым пришёл клиент, и разбор события облигации.

- **Новизна.** Проверки сделки перед подтверждением в найденных продуктах нет.
- **Встраивание.** Каждая операция через MCP по правилам Т-Инвестиций требует подтверждения клиента, это готовая точка для проверки.
- **Ценность для Т-Банка.** Меньше убытков и жалоб клиентов, совпадает с фокусом регулятора на защите частных инвесторов: средняя доходность розницы за 2023-2025 годы около 2,9% годовых ([СПМАГ по данным Банка России](https://spmag.ru/news/bank-rossii-opublikoval-rezultaty-analiza-roznichnyh-investicij-za-poslednie-3-goda)), рост дефолтов облигаций, дела о манипуляциях через Telegram.
- **Данные** есть в T-Invest API: события облигаций, флаги рисков, свечи, сделки инсайдеров, календарь отчётности.

**Три концепции для 21 ноября**, по одной на номинацию:

| Номинация | Концепция |
|---|---|
| AI-агент | 1. Второе мнение перед сделкой |
| Новый опыт | 4. Разбор заявки (Эльшод) или 6. Симулятор «что если» |
| AI-робот | 5. Объяснимый робот для автоследования |
