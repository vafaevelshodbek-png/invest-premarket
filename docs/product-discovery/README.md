## Как связаны наборы идей

Текущий набор исследования №18 состоит из [десяти кандидатов К3, К5, К7–К14](../research/investment-processes/candidates-summary.md). Для него выполнены отдельные [проверки данных №19](../research/investment-processes/candidate-data-summary.md) и [роли AI №22](../research/investment-processes/candidate-ai-summary.md). В итерации З используется собственная нумерация 1–18 и предварительные авторские оценки. Эти номера не являются идентификаторами К и не заменяют их.

| Кандидат №18 | Близкая тема итерации З | Граница соответствия |
|---|---|---|
| К3. Последствия изменения позиции | Идеи 3, 6 и 7, часть идеи 1 | К3 сравнивает варианты для позиции. Узкая карточка события является лишь частью этого результата |
| К5. Проверка сигнала | Идея 2 | Проверка утверждений вынесена в самостоятельный кандидат, в минимальную версию идеи 1 не входит |
| К7. Тренировка решений | Идея 8 | Учебный результат нужно проверять отдельно от наличия песочницы |
| К8. Робот по отчётам | Идея 13 | Для торговли нужны время появления документов и честная историческая проверка |
| К9. Исполнение заявки частями | Отдельного соответствия нет | Исполняет уже выбранную клиентом сделку |
| К10. Расхождения на счёте | Родственная тема разбору заявки, идея 4 | Состояние поручения и причины расхождений по счёту являются разными задачами |
| К11. Налоговый комплект | Идея 17 | Документы нескольких брокеров шире предупреждения о налогах перед отдельной сделкой |
| К12. Испытания робота | Отдельного соответствия нет | Это инструмент проверки торговой программы |
| К13. Портфель под поступления | Идея 18 | Заданный график выплат отличается от общей цели на одну дату |
| К14. Робот ценовых расхождений | Отдельного соответствия нет | У него отдельная стратегия и требования к рыночным данным |

Итерация З ссылается на предложение из черновика PR №52 как на источник идеи 4. Файлы этого черновика в main не включены. Проверки десяти кандидатов не подтверждают автоматически составную идею 1, её минимальный сценарий имеет собственные условия проверки.

Дальнейшая работа: сопоставить варианты на одних основаниях и зафиксировать выбор команды в №2. После выбора согласовать данные, границы сценария и ответы формы. Интервью, подключение MCP и эксперимент пока не выполнены. Работы будущих этапов зависят от допуска и отдельного поручения.
