## Документация доступа и источников

<a name="d01"></a>

**D01. [Токены T-Invest](https://developer.tbank.ru/invest/intro/intro/token), [MCP](https://developer.tbank.ru/invest/mcp).** Описаны права чтения и торговли, привязка к доступным счетам и отдельный учебный контур. Путь подключения документирован. Доступ команды, ответы инструментов и работа конкретного клиента MCP не проверены. Для К3, К8–К11, К13–К14 нельзя выводить наличие рабочего подключения из документации.

<a name="d02"></a>

**D02. [Сведения об инструментах](https://developer.tbank.ru/invest/services/instruments/methods).** Описаны лоты, номинал, НКД, купоны, сроки, признаки амортизации и плавающего купона, торговая доступность и ограничения инструментов. Наличие полей не подтверждает заполненность по каждой бумаге. Для К3 и К13 требуется проверка выбранных выпусков, для К14 также доступности нужных направлений сделки на счёте.

<a name="d03"></a>

**D03. [Рыночные данные](https://developer.tbank.ru/invest/services/quotes/marketdata), [гарантируемый период недавних сделок](https://developer.tbank.ru/invest/api/market-data-service-get-last-trades).** Есть текущие котировки, стаканы, сделки и свечи. Для недавних сделок гарантирован последний час. Это не полный исторический архив. Нужно согласовывать идентификаторы, время, единицы цены и источник торгов. Подходящая история стаканов, очередей и собственных исполнений для К9 этим источником не подтверждена.

<a name="d04"></a>

**D04. [Исторические котировки](https://developer.tbank.ru/invest/intro/intro/load_history), [архивы сделок и минутных свечей](https://developer.tbank.ru/invest/services/history-md/head-history-md), [доступ к годовым архивам](https://developer.tbank.ru/invest/services/quotes/get_history).** В документации есть CSV-форматы и примеры записей. Глубина зависит от инструмента, покрытие не полное. Для архивного доступа описан токен. Ни одна выгрузка по токену в этой работе не выполнялась. Для К7–К9 и К14 наличие нужных дат и отсутствие пропусков ещё надо проверить на выбранных инструментах.

<a name="d05"></a>

**D05. [Счёт, операции и отчётность](https://developer.tbank.ru/invest/services/operations/methods), [особенности истории операций](https://developer.tbank.ru/invest/services/operations/operations_problems).** ID операций могут меняться. После корпоративных действий история бывает неполной, документация рекомендует брокерский отчёт. В строках ряда начислений отсутствует количество бумаг, к которым относится выплата. Для К10 одной ленты операций недостаточно, для К3 текущий портфель не является архивом его прежних снимков.

<a name="d06"></a>

**D06. [Получение и чтение брокерского отчёта](https://www.tbank.ru/invest/help/educate/broker-report/about/read-n-get/), [виды отчётов и справок](https://www.tbank.ru/invest/help/educate/broker-report/about/get-report/).** Описан путь выгрузки самим владельцем и содержание отчёта. В приложении период брокерского отчёта ограничен месяцем, в личном кабинете можно выбрать период внутри календарного года. Для К10 это реалистичный ручной вход. Отчёт конкретного клиента не получен, его комплектность не установлена.

<a name="d07"></a>

**D07. Налоговые документы:** [структура налогового отчёта Т-Банка](https://www.tbank.ru/invest/help/educate/broker-report/about/tax-report/), [документы при сальдировании](https://www.tbank.ru/invest/help/educate/tax-issues/deduction/netting/), [ФНС о переносе убытков](https://www.nalog.gov.ru/rn77/taxation/taxes/ndfl/nalog_vichet/nv_ubit/).

У Т-Банка описан Excel с несколькими листами, некоторые сведения появляются только за завершённый год. Для работы с несколькими брокерами нужны документы каждого из них. ФНС указывает на ограничения по категориям операций и необходимость подтверждающих документов. Это основания для требований к входам К11. Текущий набор правил, формы второго брокера и пригодность конкретного комплекта к подаче не проверены. Налоговые ставки и готовый расчёт в этой работе не устанавливаются.

<a name="d08"></a>

**D08. [Каталог финансовой отчётности X5](https://www.x5.ru/ru/investors/financial-statements/) и [конкретный PDF за 2024 год](https://www.x5.ru/wp-content/uploads/2025/03/godovaya-konsolidirovannaya-finansovaya-otchetnost.pdf).** Открыты без входа в клиентский кабинет. PDF содержит 66 страниц, титульный лист, содержание и текст пояснений. Извлечение всех числовых таблиц и их сверка не выполнялись. Это реально доступный документ для К5 и подготовки заданий К7. Для К8 он не подтверждает наличие пригодного архива событий.

<a name="d09"></a>

**D09. [Учебный контур](https://developer.tbank.ru/invest/intro/developer/sandbox), [FAQ sandbox](https://developer.tbank.ru/invest/intro/developer/sandbox/faq_sandbox/), [различия контуров](https://developer.tbank.ru/invest/intro/developer/sandbox/url_difference).** Описана эмуляция на рыночных данных, исполнение на основе последних сделок и отличия от реального счёта. Брокерская отчётность в sandbox недоступна. Купоны, дивиденды и налоги нельзя проверять как реальные начисления. Реальные расходы заимствования и поведение очереди не подтверждаются такой эмуляцией. Подходит для проверки соединения и ограниченной логики К8, К9, К12 и К14, но не заменяет нужные данные и проверку реальной торговли.

<a name="d10"></a>

**D10. [Т-Банк об офертах облигаций](https://www.tbank.ru/invest/help/educate/how-it-works/ways-to-invest/bonds-profit/).** Описаны дата оферты в карточке и подача заявки через приложение. Документ не подтверждает наличие у нашего подключения автоматической подачи и всех статусов приёма. Для режима события в К3 сначала нужен конкретный выпуск, условия события и брокерский срок. Признака оферты в каталоге недостаточно для прохождения всего процесса.

<a name="d11"></a>

**D11. [Условия использования API](https://developer.tbank.ru/invest/intro/faq).** FAQ указывает, что API предоставляется клиентам без права ретрансляции данных. Поэтому прототип с доступом владельца нельзя автоматически считать разрешённым источником публичной выдачи чужим пользователям. Для формата продукта отдельно проверяются хранение, передача провайдеру модели и распространение данных. Публичная доступность документов эмитента также сама по себе не устанавливает условия массового сбора и переиздания.

<a name="d12"></a>

**D12. [Календарь будущих выплат Т-Банка](https://www.tbank.ru/invest/help/educate/yield-analysis/about/folio-lookup/).** Справка прямо различает дату выплаты в календаре и фактическое поступление на счёт. Это существенно для К3, К10 и особенно К13, где клиент привязывает деньги к собственным расходам. Календарь не является гарантией получения всей суммы в нужный день.

## Публичный пример: что удалось подтвердить сейчас

Это ручная проверка доступности и содержания документа, а не испытание модели. Ниже искусственно составленные утверждения, не обращения реальных клиентов.

| Утверждение | Что подтверждает просмотр |
|---|---|
| «Документ X5 относится к году, закончившемуся 31 декабря 2024 года» | Да, это указано на титульном листе. |
| «Это консолидированная отчётность по МСФО» | Да, название и вид отчётности указаны на титуле. Нельзя подменять ею отдельную отчётность юридического лица по РСБУ. |
| «Документ опубликован 21 марта 2025 года» | Такая дата есть в каталоге. В пояснении 2.1 на странице 16 указано утверждение 20 марта и публикация 21 марта. |
| «Документ был доступен ровно в начале торгов 21 марта» | Не подтверждено: просмотренные сведения не содержат точного времени первой доступности и истории замены файла. |

**Следствие для выбора.** Для К5 уже есть первичный документ и проверяемые текстовые утверждения. Для К8 всё ещё нет основания привязать сделку к точному моменту появления этого документа. Разница статусов связана с разными требованиями к данным.

## Ограничения, влияющие на первую проверку

Выдержка из [лимитов T-Invest](https://developer.tbank.ru/invest/intro/intro/limits) и документации D04. Значения проверены 14 ноября 2026 года, относятся к описанным видам запросов. Это не измеренная скорость продукта.

| Ограничение | Значение по документации | Практическое следствие |
|---|---|---|
| Рыночные данные | 600 запросов в минуту | Выгрузки и сравнения делятся на части. |
| Сведения об инструментах / списки основных типов инструментов | 200 / 15 запросов в минуту | Подробные условия бумаг и массовые списки имеют разные квоты. |
| Операции / формирование отчётов через gRPC | 200 / 5 запросов в минуту | К10 не должен заново формировать отчёт для каждого вопроса. |
| Стакан в потоке | Интервал отправки 100 мс | Не подтверждает полный журнал каждого биржевого изменения для К9. |
| Минутные свечи | Один запрос до суток, максимум 2400 свечей | Период запроса не равен глубине всей доступной истории. |
| Дневные свечи | Один запрос до 6 лет, максимум 2400 свечей | Фактический старт и полнота зависят от бумаги. |
| Секундные свечи | Доступны только за последний месяц | Не заменяют многолетнюю историю исполнения и реакций на события. |

У пользователя квоты общие для счетов и токенов, политика динамическая. Для этой предварительной проверки не требуется работа на предельной нагрузке. Полные таблицы уже есть в №30, здесь оставлены ограничения, меняющие оценку кандидатов.

## Что осталось неизвестным

Рабочие токены и права счёта, наполненность полей выбранных бумаг, фактические выгрузки истории, клиентские документы и их контрольные расчёты, журнал исполнения, подключаемая программа робота и программный доступ к выбранной текстовой модели не получены. Это разные условия по кандидатам, они перечислены в карточках и не заменены общим утверждением «API существует».

Часть страниц портала при прямом открытии возвращала ошибку. Для них использованы тексты официальных страниц в поисковой выдаче. Это проверка документации, не успешный вызов сервиса. Каталог X5 и конкретный PDF открыты напрямую.
