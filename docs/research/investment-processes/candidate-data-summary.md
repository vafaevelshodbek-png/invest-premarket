# №19. Доступность данных для десяти кандидатов

Редакция от 14 ноября 2026 года, согласована пользователем для публикации в PR. [Подробности по каждому кандидату](candidate-data-check.md) · [Источники и фактически просмотренный пример](candidate-data-sources.md).

Работа выполнена заново по [описанию №19](https://github.com/vafaevelshodbek-png/invest-premarket/issues/19), для десяти кандидатов из [PR №57 по №18](https://github.com/vafaevelshodbek-png/invest-premarket/pull/57). Предыдущие результаты №19 не использовались. Технический доступ к личному счёту, API и MCP не проверялся.

## Краткое заключение

Статус относится к минимальной проверке основного результата кандидата. Он не означает готовность всего продукта или разрешение на реальную торговлю.

- **Доступно:** необходимые материалы для указанной узкой проверки уже открыты публично.
- **Условно доступно:** источник и путь получения известны, но нужен конкретный документ, счёт, код или подготовка контрольного набора.
- **Неизвестно:** доступ к критическому входу не подтверждён. Упрощённое демо не снимает этот вопрос.

## С чего можно продолжить

**Без доступа к счёту:** К5 можно проверять на открытых документах и явно заданных утверждениях. Для К7 можно готовить учебные случаи, для К12 сценарии сбоев, но контрольный набор и подключение робота ещё предстоят.

**После получения конкретных входов:** К3, К10, К11 и К13. Ручная загрузка документов или портфеля подходит для первой проверки. Подключение MCP не требуется ради самого факта демонстрации расчёта или разбора.

**До дальнейшей проработки роботов:** у К8 и К9 сначала подтвердить критические данные. У К14 проверить доступность выбранной пары и стоимость двух частей позиции. Наличие котировок и торговых команд не подтверждает воспроизводимость стратегии.

Это приоритет снятия неопределённости по данным, а не выбор победителя. Роль AI сравнивается в №22, идея выбирается в №2. Подробная спецификация и архитектура для всех десяти вариантов здесь не разрабатываются.

## Что сделано сейчас

Прочитаны условия и реальные зависимости №19: №18 и №30. Проверена публичная документация доступа, исторических данных, отчётности, ограничений и учебного контура. Открыты каталог отчётности X5 и конкретный PDF за 2024 год. По каждому кандидату определены минимальные входы, период, интеграция, быстрая проверка и стоп-фактор.

Клиентские документы, рыночные выгрузки по токену и журналы торгов не получены. Программные интеграции, расчёты доходности и пользовательские испытания не выполнялись. Материал подготовлен для публикации в отдельном PR по №19. Выбор идеи не зафиксирован.
