## Различия по трём направлениям

- **AI-помощник, №17–20:** диалог помогает уточнить вопрос, результат остаётся в карточке, документе или плане. История переписки не должна быть единственным способом найти числа и основания.
- **Новый пользовательский опыт, №21–23:** главное действие происходит на экране сравнения, в форме заявки или симуляторе. Диалог дополняет это действие.
- **AI-торговый робот, №24–26:** нужны конструктор стратегии, управление запуском и журнал. Для исполнения требуется постоянно работающий исполнитель. Название «чат-бот» не описывает весь этот продукт.

## Что потребуется для разных форматов

| Вариант | Что меняется для клиента | Ограничение |
|---|---|---|
| Самостоятельный сервис по выгрузке | Загружает данные и обновляет их вручную | Результат относится к дате снимка |
| Самостоятельный сервис с подключённым счётом | Проходит подключение и использует ещё одно приложение | Нужны доступ к счёту и поддержка подключения |
| Экран внутри брокерского приложения | Работает рядом со счётом и привычными действиями | Требуется участие владельца приложения |
| Помощник в существующем приложении агента | Настраивает подключение, осваивает диалог и проверку результата | Интерфейс и подтверждения зависят от приложения |
| Уведомление или отчёт | Получает событие либо результат за период | Для разбора и действия нужен понятный переход |

MCP является способом подключения. Он сам не создаёт экран внутри брокерского приложения и не гарантирует конкретную форму подтверждения. [Основание](product-formats-sources.md#f04).

## Результат задачи

Для всех 26 ситуаций указаны формат, результат, следующий шаг и ограничения. Для клиентских историй дополнительно описаны запуск, два варианта размещения, неподходящий для этой задачи вариант и способ сравнить удобство. Денежная стоимость перехода не измерялась. Учтены его составляющие: настройка, перенос данных, обучение и поддержка.

Материал готов для формирования кандидатов в [№18](https://github.com/vafaevelshodbek-png/invest-premarket/issues/18), описания продукта в [№4](https://github.com/vafaevelshodbek-png/invest-premarket/issues/4) и проверки встраивания в [№37](https://github.com/vafaevelshodbek-png/invest-premarket/issues/37).
