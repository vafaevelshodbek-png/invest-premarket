# Аудит решения №30

Проверено 9 ноября 2026 года. Исходный материал опубликован в [№30](https://github.com/vafaevelshodbek-png/invest-premarket/issues/30) 7 ноября и [сохранён полностью](archive/issue-30-2026-11-09.md). [План аудита](audit-plan.md) определяет границы работы.

## Вердикт

Исходное решение пригодно как документальная основа для №19, но требовало дополнения перед использованием для выбора источника и формата продукта. Полностью повторять исследование не нужно. Автор собрал содержательную матрицу, отметил неопределённости и не выдал документацию за успешное подключение аккаунта.

Существенные недостатки относятся к полноте: отсутствует отдельный источник исторических архивов, недостаточно явно описано ограничение ретрансляции данных, таблица квот не показывает несколько важных ограничений нагрузки. Эти вопросы исправлены в новой редакции.

После доработки материал можно использовать с указанными ограничениями. Доступ команды, состав MCP-инструментов после подключения, качество данных нужного кандидата и допустимость конкретного публичного сервиса всё ещё не проверены. Завершение №30 и принятие PR остаются отдельным решением.

Бесплатный доступ не означает право ретранслировать данные | Вынесено прямое ограничение из [FAQ API](https://developer.tbank.ru/invest/intro/faq). Допустимость конкретного способа распространения не объявлена установленной |

По ней нельзя работать со всеми документированными интервалами | Таблица расширена до всех 16 интервалов страницы, сохранено различие между окном запроса и глубиной истории. [Исторические котировки](https://developer.tbank.ru/invest/intro/intro/load_history) |

Успешное обращение зависит от доверия к цепочке в конкретном окружении | В справочнике сохранена необходимость доверенных сертификатов и добавлена конкретизация НУЦ Минцифры. Проверка сертификатов не отключалась. [Подключение](https://developer.tbank.ru/invest/intro/developer/network) |

## Что подтвердилось

| Утверждение автора | Результат проверки |
|---|---|
| News ограничен 24 часами, фундаментальные показатели покрывают не все активы и могут обновляться с задержкой | Подтверждено доступным текстом [официальной страницы](https://developer.tbank.ru/invest/services/instruments/head-instruments). Ноль в ответе GetAssetFundamentals документирован как отсутствие данных. Это правило не распространено на все числовые поля API |
| GetLastTrades гарантирует последний час | Подтверждено [контрактом метода](https://developer.tbank.ru/invest/api/market-data-service-get-last-trades). Это не отрицание существования файловых архивов |
| GetOperationsByCursor использует страницы до 1000 операций, старый GetOperations возвращает последнюю тысячу | Подтверждено [контрактом](https://developer.tbank.ru/invest/api/operations-service-get-operations-by-cursor) и [FAQ](https://developer.tbank.ru/invest/services/operations/faq_operations) |
| ID операций могут меняться, история после корпоративных действий может быть неполной | Подтверждено [особенностями операций](https://developer.tbank.ru/invest/services/operations/operations_problems). Рекомендация не считать ID неизменяемым ключом сохранена |
| Событие выплаты и фактическое поступление владельцу различаются | Различие источников и счёта сохранено. Проверка конкретного начисления не проводилась |
| Статусы поручений и история операций обновляются с разной задержкой | Подтверждено [порядком доставки обновлений](https://developer.tbank.ru/invest/intro/developer/speedup). Интервал отправки сообщений не объявлен полной задержкой системы |
| Песочница не подтверждает реальные налоги, выплаты и исполнение | Подтверждено [описанием песочницы](https://developer.tbank.ru/invest/intro/developer/sandbox) и [сравнением контуров](https://developer.tbank.ru/invest/intro/developer/sandbox/url_difference) |
| В описании маржинальных расчётов песочницы есть расхождение | Подтверждено сопоставлением общей страницы с [релизом 1.51](https://developer.tbank.ru/invest/release/latest). Неопределённость сохранена, одна версия описания не выбрана произвольно |
| API и MCP нельзя считать одним проверенным набором методов | Сохранено. [Разработчик MCP](https://habr.com/ru/companies/tbank/articles/1086714/) описывает группы возможностей и адреса, [спецификация](https://modelcontextprotocol.io/specification/2025-06-18/server/tools) предусматривает получение списка и схем. Актуальный список инструментов не запрашивался |
| На первом отборе разрешены собственные модели, облака и API | Подтверждено [сохранённым текстом формы](https://github.com/vafaevelshodbek-png/invest-premarket/wiki/Hackathon#требования-первого-отбора). Это основание со слов переданного задания, а не повторное получение формы из кабинета организаторов |

## Полнота переноса

Все 18 исходных строк матрицы преобразованы в раскрываемые карточки с методами, данными, ограничениями, основаниями и проверками. Добавлена отдельная карточка архивов. Исходные сведения о двух контурах, четырёх выбранных интервалах свечей, пяти группах квот и шести дальнейших проверках сохранены либо включены в расширенные таблицы.

Сохранены форматы и денежные типы, часовой пояс, особенности истории и обновления, права и жизненный цикл токенов, безопасность, ограничения песочницы, контекст первого отбора и передача в №19. Все 32 исходных адреса источников присутствуют в справочнике, добавлены четыре уточняющих источника. Буквенные статусы заменены словами. Полная исходная формулировка остаётся в архиве.

Краткий обзор показывает группы возможностей и ограничения, полный справочник сохраняет технические подробности. Текст из описания Issue удаляется только после проверки опубликованных файлов. Критерии, входы и получатели результата в самой задаче сохраняются.

## Границы проверки источников

Прямое получение большинства страниц developer.tbank.ru и PDF правил в локальном окружении завершилось ошибкой проверки цепочки сертификатов. Повтор с доступными сертификатами системного хранилища не устранил её. Проверка TLS не отключалась и системное доверие не изменялось.

Ключевые утверждения сверены по доступным индексированным копиям страниц официального портала, обычно с датой обхода за два дня до аудита. Полный текст статьи разработчика MCP и спецификации MCP получен напрямую. Текст формы проверен по Wiki. Эти способы доступа различаются, все 32 страницы не объявляются полностью заново прочитанными.

Текущая редакция PDF правил не получена. Ссылка сохранена как исходное основание. Доступ к API и MCP, токены, инструменты конкретного подключения, торговые и тестовые операции, квоты аккаунта и качество данных выбранного инструмента не проверялись. Такое тестирование не входит в документальный результат №30.

## Проверка подачи

Обзор, полный справочник и аудит отрисованы рендерером Markdown GitHub и просмотрены локально при ширине 1280 и 390 пикселей. В справочнике отрисованы все 19 раскрываемых карточек и 23 таблицы. Общая страница не выходит за ширину экрана. На узком экране три технические таблицы справочника и две таблицы аудита требуют прокрутки внутри таблиц, содержимое сохранено. Краткий обзор помещается по ширине в обоих размерах.

Машинная сверка проверяет все пять полей каждой из 18 исходных строк, 32 исходных адреса, шесть дальнейших проверок, исходные числовые ограничения и локальные ссылки. Полный архив совпадает с исходным описанием Issue. После публикации дополнительно проверяется совпадение файлов GitHub с проверенным коммитом.

Отдельно проверена чувствительность сверки: имитации потери поля матрицы, адреса источника и интервала свечей были обнаружены. Эти проверки выполнялись в памяти, файлы материалов не изменялись.

Локальное оформление близко к GitHub, но не подтверждает все особенности его мобильного приложения. Число строк и работа ссылок не доказывают удобство чтения или понимание человеком.
