# Возможности и ограничения T-Invest API и MCP

Документальный разбор для [задачи №30](https://github.com/vafaevelshodbek-png/invest-premarket/issues/30), редакция от 14 ноября 2026 года. Доступ команды к счетам, API и MCP не проверялся.

## Возможности API

T-Invest API даёт основу для продуктов, которым нужны рыночная информация, сведения об инструментах, данные разрешённых счетов пользователя и сопровождение его поручений. Для исторического анализа предусмотрены свечи и файловые архивы сделок. Покрытие конкретных бумаг и периодов требует проверки.

Доступ к счетам ограничивается правами токена. Календарь отчётности содержит даты и периоды публикаций, а глубина истории зависит от инструмента и интервала свечей. [Права доступа](https://developer.tbank.ru/invest/intro/intro/token), [состав календаря](https://developer.tbank.ru/invest/services/instruments/methods#getassetreportsresponse), [глубина истории](https://developer.tbank.ru/invest/intro/intro/load_history).

## Возможности MCP

MCP позволяет агенту использовать возможности Т-Инвестиций в ходе диалога и сценария из нескольких обращений к сервису. Банк описывает сценарии работы с рынком, портфелем, операциями и поручениями. [Официальное описание MCP](https://developer.tbank.ru/invest/mcp).

[Подробнее о MCP](reference.md#mcp): что даёт такое подключение, что остаётся работой продукта и какие ограничения влияют на осуществимость идеи.

## Ограничения, важные для продукта

- **Данные.** Нужная история, полнота и актуальность подтверждаются отдельно. Архив сделок не заменяет исторический стакан.
- **Доступ.** Область разрешённых счетов и действий определяется правами пользователя и токена.
- **Надёжность.** Квоты, задержки обновления и ошибки агента ограничивают возможную частоту и автономность работы.
- **Проверка.** Sandbox помогает проверить технический сценарий. Он не воспроизводит все реальные выплаты, налоги и условия исполнения.
- **Формат продукта.** Условия хранения, внешней обработки и распространения данных нельзя выводить из бесплатности API.

Основания и последствия разобраны в разделах [API](reference.md#limits), [MCP](reference.md#mcp) и [sandbox](reference.md#sandbox-details).

## Что передаётся в №19

[Проверка кандидатов](https://github.com/vafaevelshodbek-png/invest-premarket/issues/19) получает [перечень открытых условий](reference.md#handoff): доступ к обязательным входам, пригодность истории, соответствие MCP сценарию и ограничения формата продукта.

Идея, архитектура и преимущество AI этим разбором не выбираются. Успешная интеграция сама по себе не подтверждает пользовательскую ценность.
