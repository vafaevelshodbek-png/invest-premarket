# Данные и инструменты Т-Инвестиций

Через T-Invest API можно получать сведения об инструментах, рынке и своём счёте, а с подходящими правами отправлять поручения. MCP позволяет агенту обращаться к инструментам сервера. Состав этих инструментов проверяется после подключения, он не устанавливается по одному списку методов API.

Это документальный разбор для [№30](https://github.com/vafaevelshodbek-png/invest-premarket/issues/30) от 9 ноября 2026 года. Подключение аккаунта и выполнение методов не проверялись.

## Что влияет на выбор идеи

**История неодинакова у разных данных.** Новости в методе News ограничены 24 часами. Для свечей есть запросы и файловые архивы, для обезличенных сделок есть отдельные дневные архивы. Покрытие нужных бумаг и дат проверяется отдельно. Наличие текущего стакана не доказывает доступ к его истории. [Особенности данных](https://developer.tbank.ru/invest/services/instruments/head-instruments), [исторические архивы](https://developer.tbank.ru/invest/services/history-md/head-history-md).

**Бесплатность данных не даёт права ретранслировать их.** FAQ ограничивает использование API клиентами Т-Инвестиций без права на ретрансляцию. Формат публичного продукта и передачу данных внешним сервисам нельзя считать разрешёнными по умолчанию. [FAQ API](https://developer.tbank.ru/invest/intro/faq).

**Песочница проверяет технический сценарий.** В ней не начисляются купоны и дивиденды и не рассчитываются налоги. Комиссия и исполнение упрощены. Общая страница и релизы расходятся в описании части маржинальных расчётов. Успех в тестовом контуре не подтверждает доходность стратегии или доступность реальной операции. [Особенности песочницы](reference.md#sandbox-details).

**Номинальных квот недостаточно для расчёта нагрузки.** Есть общие и специальные лимиты методов, соединений и подписок. Доставка котировок с интервалом 100 мс не означает такую же задержку системы. [Лимиты и обновление](reference.md#limits).
