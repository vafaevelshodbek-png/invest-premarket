# Инвест. Премаркет

Командное пространство разработки AI-продукта для программы Т-Инвестиций.

**[Wiki — контекст и документация](https://github.com/vafaevelshodbek-png/invest-premarket/wiki) · [Доска задач и Roadmap](https://github.com/users/vafaevelshodbek-png/projects/1) · [Создать задачу](https://github.com/vafaevelshodbek-png/invest-premarket/issues/new/choose)**

В Wiki: этапы, исследование, идеи, решения, архитектура, эксперименты, данные и сдача. Здесь: исходный код, конфигурация и шаблоны совместной разработки. Идея и стек пока не выбраны; структура приложения появится после определения MVP.

Начните с [главной страницы Wiki](https://github.com/vafaevelshodbek-png/invest-premarket/wiki) и [правил командной работы](https://github.com/vafaevelshodbek-png/invest-premarket/wiki/Team-work). Для изменения кода создайте Issue, короткую ветку и Pull Request со способом проверки. Подробная инструкция запуска будет опубликована в [Wiki](https://github.com/vafaevelshodbek-png/invest-premarket/wiki/Architecture) после сборки MVP.
