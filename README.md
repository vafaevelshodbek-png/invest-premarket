## Разработка

В репозитории хранятся код и настройки приложения, а документация ведётся в Wiki. Идея и стек пока не выбраны, поэтому структура приложения появится после согласования MVP.

1. Выберите задачу и создайте ветку для изменений.
2. Откройте Pull Request, указав результат и способ проверки.
3. После проверки другим участником объедините изменения и при необходимости обновите Wiki.
